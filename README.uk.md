# StickerMotion

[English version](README.md)

StickerMotion перетворює статичний малюнок персонажа (PNG з прозорим фоном) на анімовані стікери й емоути для Twitch, Discord, Telegram і OBS. Сервіс описує природну дію персонажа, анімує її моделлю image-to-video, вирізає персонажа назад у повну прозорість, робить безшовний луп і експортує файл під кожну платформу так, щоб він уклався в її ліміти розміру й ваги. Готові стікери можна одним натисканням опублікувати в пак Telegram і на сервер Discord.

Це невеликий сервіс для одного користувача на власному сервері: веб-інтерфейс із паролем плюс інструмент командного рядка.

## Можливості

- **ШІ-анімація з одного PNG.** Модель зору пропонує, що робить персонаж (позіхає, махає, кліпає), текст можна виправити, далі Wan 2.2 image-to-video анімує дію.
- **Повна прозорість.** Ролик генерується на однотонному зеленому фоні й вирізається назад в RGBA з м'якими краями; відтінок шкіри, що поплив у відео, виправляється.
- **Безшовний луп.** Перший кадр дорівнює останньому, луп обрізається на найближчому до початку кадрі, запасний варіант ping-pong.
- **Декор окремими шарами.** Зірки, місяць, сердечка чи «Zzz» поруч із персонажем знаходяться й анімуються самостійно (мерехтіння, гойдання, плавання, пульсація), а не рухаються разом з головою.
- **Фокус для емоутів.** Емоути, які показуються на 28 px, обрізаються до обличчя й жесту, щоб лишатися читабельними в чаті.
- **Один майстер, багато експортерів.** Twitch GIF (авто і ручний 28/56/112), стікер (APNG) і емодзі Discord, відеостікер і кастомне емодзі Telegram (WEBM VP9 з альфою), оверлей для OBS. Кожен файл перевіряється на ліміти платформи; вага підганяється під 95% ліміту.
- **Варіанти.** 2-3 ролики з різним seed, щоб вибрати найкращий рух; сподобаний рух можна використати пізніше без нової оплати.
- **Публікація.** Стікерпак і пак кастомних емодзі Telegram, анімований емодзі й стікер Discord, готовий архів з інструкцією для Twitch.
- **Контроль витрат.** Ліміт на одну генерацію і денний ліміт перевіряються перед кожним платним викликом, кожен запит записується в журнал витрат.
- **Процедурні пресети** (bounce, squash and stretch, wiggle) як безкоштовний запасний режим без ключа API.

## Приклад результату

Вхід: намальований мультяшний лис сидить з піднятою лапою, навколо нього плавають три маленькі сердечка, фон прозорий.

Результат за хвилину-дві: лис двічі махає лапою, кліпає й нахиляє голову, потім повертається у початкову позу, а сердечка самі по собі плавають і пульсують. Ви отримуєте відеостікер Telegram 512 px до 256 КБ, емодзі Telegram 100 px, стікер Discord 320 px, емодзі Discord 128 px, GIF для Twitch 28, 56, 112 і 224 px (емоути обрізані до обличчя) і великий WEBM для OBS, усе з лупом без помітного шва.

## Як це працює

```
PNG з прозорістю
  -> опис дії (модель зору gpt-5-nano, можна редагувати)
  -> кадрування на зеленому полотні 16:9, декор прибирається
  -> Wan 2.2 i2v fast, 480p, перший кадр = останній
  -> хромакей назад в RGBA, виправлення відтінку шкіри
  -> безшовний луп, декор повертається окремими анімованими шарами
  -> майстер-анімація (RGBA-кадри)
  -> експортери під платформи, вага під 95% ліміту, валідатор
  -> завантаження або публікація (Telegram, Discord, архів для Twitch)
```

Детальніше: [docs/how-it-works.md](docs/how-it-works.md).

## Швидкий старт (Docker)

Потрібні Docker з Docker Compose і токен API [Replicate](https://replicate.com).

```bash
git clone https://github.com/webmosaic/stickermotion.git stickermotion
cd stickermotion
cp .env.example .env
# у .env задайте APP_PASSWORD і REPLICATE_API_TOKEN
docker compose up -d --build
```

Відкрийте http://127.0.0.1:8000, увійдіть з паролем `APP_PASSWORD` і завантажте PNG. Порт відкритий лише на localhost; щоб сервіс був доступний з інтернету, поставте його за nginx з HTTPS (див. [docs/getting-started.md](docs/getting-started.md)).

Без Docker: Python 3.12, ffmpeg з libvpx-vp9, далі `pip install .` і `stickermotion serve`.

## Вартість

Генерація йде через Replicate з вашим власним токеном, оплата напряму Replicate.

- Один ролик Wan 2.2 i2v fast у 480p (81 кадр) коштує близько **0.05$**. 720p коштує близько 0.11$ і в розмірах стікерів не дає помітного приросту.
- Допоміжні виклики `openai/gpt-5-nano` (опис дії, переклад, перевірка декору, фокус емоута) коштують частки цента, близько 0.0002$ кожен.
- Отже, один стікер це близько 0.05$, або 0.10-0.15$, якщо генерувати 2-3 варіанти. Повторна обробка збереженого ролика, завантаження і публікація безкоштовні.
- Запити, відхилені модерацією Replicate (E005), не оплачуються.

Ціни перевірено в жовтні 2026 і вони можуть змінитися; актуальні дивіться на сторінках моделей на Replicate.

## Обмеження

- Один користувач: один пароль, без акаунтів і ролей.
- Веб-інтерфейс і його повідомлення українською; опис дії можна писати українською або англійською. CLI і документація англійською.
- На вході потрібен PNG зі справжньою прозорістю; видалення фону не входить в основний шлях.
- ШІ-генерація потребує акаунта Replicate і доступу до інтернету, локального режиму на GPU немає. Сам сервіс працює на сервері без GPU.
- Wan 2.2 fast не має негативного промпту, тому результат залежить від seed; генерація варіантів і вибір найкращого є частиною роботи.
- Twitch не має API для завантаження емоутів: сервіс готує файли й інструкцію, завантаження вручну.
- Кастомні емодзі Telegram на практиці обмежені 64 КБ, що обмежує деталізацію і частоту кадрів емодзі.
- Одночасно виконується одна генерація; платні виклики йдуть по черзі, щоб не впиратися в ліміти частоти Replicate.

## Розробка

```bash
python3.12 -m venv .venv
. .venv/bin/activate
pip install -e ".[dev]"
pytest                 # швидкий набір, без мережі й витрат
pytest -m slow         # повна матриця рендеру через CLI
ruff check . && ruff format --check .
```

Тести використовують фейкові транспорти Replicate, Telegram і Discord; жоден запит не виходить за межі машини. Тестові зображення в `tests/fixtures/` синтетичні, їх можна перегенерувати командою `python scripts/make_fixtures.py`.
